# SCDO x402 wallet plugin for GAME

Gives a GAME agent its own **SCDO x402 wallet** (USDC on Base), so it can pay HTTP 402 URLs within caps. Each registration, wallet, payment and booked income is written as a signed row on the public [SCDO Agent Ledger](https://scdo.com.au/agent/?src=dir-game-python), and the agent gets an ERC-8004 identity.

Ported from the `virtuals` extra of [`scdo-agent-tools`](https://github.com/SCDOLAB/scdo-agent-plugins) (MIT).

## Features

| GAME function | What it does |
|---|---|
| `scdo_register_agent` | Create or reuse the agent's SCDO identity and wallet, then start signed heartbeats |
| `scdo_create_wallet` | Create or reuse the agent's USDC wallet on Base mainnet (`base`) or Base Sepolia (`base-sepolia`) |
| `scdo_get_balance` | On-chain USDC and Agent Ledger balances |
| `scdo_pay_x402` | Pay an x402 (HTTP 402) URL from the agent's wallet and return the resource |
| `scdo_book_income` | Book a settled payment the agent received as income on the ledger |

- **Keys stay local.** Keys are generated by the open-source `scdo-agent` CLI inside the agent's data directory (default `~/.scdo-agent`). This plugin never reads key files or prints secrets.
- **Caps.** 0.001 to 1 USDC per payment, 100 payments and 20 USDC per day, plus per-agent caps (`max_usdc`, `daily_usdc`; defaults 0.10 and 1.00).
- Payments use x402 EIP-3009 transfers, so agent wallets need no ETH for gas.

## Installation

From the root of this repository:

```bash
pip install -e plugins/scdo
```

The plugin calls the `scdo-agent` CLI. On Linux (x86-64 or ARM64) the CLI is downloaded automatically into the data directory the first time it is needed. To turn that off, set `SCDO_AGENT_NO_DOWNLOAD=1` and point `SCDO_AGENT_BIN` at your own binary. See https://scdo.com.au/linux-agent/.

Optional environment variables:

| Variable | Meaning |
|---|---|
| `SCDO_AGENT_BOT` | Agent name (default `game-agent`) |
| `SCDO_AGENT_DATA` | Data directory for keys and state (default `~/.scdo-agent`) |
| `SCDO_AGENT_NETWORK` | `base` (default) or `base-sepolia` |
| `SCDO_AGENT_BIN` | Path to an existing `scdo-agent` binary |

## Usage

As a ready-made worker:

```python
import os
from game_sdk.game.agent import Agent
from scdo_plugin_gamesdk import ScdoWalletPlugin

scdo = ScdoWalletPlugin(bot="my-game-agent", max_usdc="0.05", daily_usdc="0.50")

agent = Agent(
    api_key=os.environ["GAME_API_KEY"],
    name="SCDO wallet demo",
    agent_goal="Keep this agent registered and report its USDC balance.",
    agent_description="An agent with its own SCDO x402 wallet (USDC on Base).",
    get_agent_state_fn=lambda function_result, current_state: {},
    workers=[scdo.get_worker()],
)
agent.compile()
agent.run()
```

Or add the functions to your own worker's `action_space`:

```python
action_space = [*my_functions, *scdo.get_functions()]
```

Full scripts are in [`examples/`](examples/). Copy `examples/.env.example` to set `GAME_API_KEY`.

Fund the wallet by sending USDC on Base to the address that `scdo_register_agent` returns. For testing, use `base-sepolia`.

## Tests

The tests run offline with a fake CLI and fake HTTP, so they use no keys, network or funds:

```bash
pip install -e "plugins/scdo[test]"
pytest plugins/scdo/tests
```

## Troubleshooting

- **`scdo-agent` not found** on macOS or Windows: the automatic download covers Linux only. Install the CLI and set `SCDO_AGENT_BIN`.
- **`cap` error**: the amount is outside the caps listed above. Lower `max_usdc` or the price.
- **Wallet balance is 0**: send USDC on Base to the wallet address (not ETH).
