# Junct Plugin for GAME SDK

Access **20+ hosted crypto MCP servers** from any Virtuals agent.

Powered by [Junct](https://junct.dev), the agent-readiness layer for crypto.

## Install

```bash
pip install junct_game_sdk
```

## Tools

| Tool | Description |
|------|-------------|
| `list_junct_servers` | List all available servers |
| `list_junct_tools` | Discover tools on a server |
| `call_junct_tool` | Call any tool on any server |
